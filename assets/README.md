# Icône

`icon.svg` est un dessin original du projet : bulle de discussion et deux lignes, sans logo du journal. Le build utilise Sharp pour produire les variantes PNG 16, 32, 48 et 128 px dans `dist/icons/`.

Le format 128 px conserve une zone transparente de 16 px autour du dessin. Aucun générateur d’images, stock ou ressource distante n’est utilisé. Licence MIT, comme le code du projet.
