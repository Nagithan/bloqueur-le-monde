# Réglages et commandes de filtrage

Mode : Operate. Extension locale de l’interface du Monde, sans nouvelle identité graphique. Le lecteur doit bloquer, revenir sur un choix et comprendre les exceptions communautaires.

## Direction contract

THESIS : une liste de préférences de lecture, directement manipulable ; le blocage rejoint la barre « Signaler » du site. Les réglages montrent d’abord les choix d’auteurs, pas un tableau de statistiques.

OWN-WORLD : héritage du Monde pour les commandes injectées ; fonds neutres, encre bleu nuit, bordures fines et actions sobres. Polices déjà chargées sur le site ; pile système lisible pour les options. Pas de logo du journal, pas de dépendance distante.

STORY : le lecteur confirme un blocage, voit le nombre réellement masqué, puis peut rétablir un auteur avec une exception qui survit aux mises à jour.

FIRST VIEWPORT : titre et état du filtrage en haut ; liste recherchable à gauche avec ajout et trois états par auteur ; réglages communautaires et export à droite. Sur petit écran, les réglages suivent la liste. La confirmation garde une action d’annulation visible et un retour de focus fiable.

FORM : extension locale précisément spécifiée de l’autorité existante, sans tirage de concept (seed : non applicable). L’interaction caractéristique est l’aller-retour immédiat entre masquage et restauration, avec compteur corrigé sans rechargement.

FINISH : unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Limites établies : aucun identifiant stable d’auteur encore vérifié dans le DOM ; pseudonyme exact annoncé comme repli. La page de compte externe n’est pas requise pour gérer les préférences locales.
