# Fiche Chrome Web Store — texte prêt à reporter

## Nom

Bloqueur Le Monde

## Description courte

Masquez les commentaires d’auteurs choisis sur Le Monde. Préférences locales, liste modifiable, sans envoi de données.

## Description détaillée

Retrouvez le fil des discussions du Monde en masquant les commentaires d’auteurs que vous choisissez.

Un bouton « Bloquer cet utilisateur » apparaît à côté de « Signaler ». Après confirmation, les commentaires correspondants sont masqués dans la discussion et sur les articles suivants, y compris ceux qui se chargent après son ouverture.

Vous gardez le contrôle :

- Annulez un blocage ou affichez temporairement les commentaires masqués.
- Gérez les auteurs depuis la discussion ou les réglages de l’extension.
- Choisissez « Toujours masquer », « Toujours afficher » ou « Suivre la communauté ».
- Consultez le nombre de commentaires masqués parmi ceux chargés.
- Conservez les réponses des autres auteurs sous un commentaire masqué.
- Exportez et importez vos préférences dans un fichier local.

Une liste communautaire est fournie et active par défaut. Elle contient initialement le pseudonyme Peps72. Vous pouvez la désactiver ou exempter n’importe quelle entrée ; vos exceptions restent prioritaires lors des mises à jour. Chacun peut proposer une correction, un ajout ou un retrait sur GitHub, avant revue.

Le filtrage fonctionne localement. Aucun compte propre à l’extension, publicité, télémétrie ou serveur applicatif. Les préférences ne sont pas envoyées aux développeurs ou au Monde, ni synchronisées par Google. L’extension accède uniquement à www.lemonde.fr. Les pseudonymes, règles et réglages sont conservés dans son stockage local.

Le site peut observer les modifications de visibilité et les préférences affichées lorsque vous ouvrez le gestionnaire sur la page. Le masquage reste un choix de lecture local au profil Chrome : il ne bloque pas le compte de l’auteur ni ses réponses. En l’absence d’identifiant public stable, les pseudonymes sont comparés exactement ; les homonymes sont concernés et un changement de pseudonyme peut ne pas être reconnu.

Cette extension indépendante n’est ni éditée, ni sponsorisée, ni approuvée par Le Monde. Elle n’accorde pas d’accès aux commentaires réservés aux abonnés. Chrome 120 ou plus récent sur ordinateur est nécessaire.

Code, documentation et contributions : https://github.com/Nagithan/bloqueur-le-monde
